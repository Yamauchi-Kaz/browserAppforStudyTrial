# 画像AI用プロンプト（モンスター5体・背景5枚）

ChatGPT・Gemini などの画像AIで作り、チャットで送ってください。ゲームへの組みこみ（背景の切りぬき、大きさの調整、動きの設定）はこちらでやります。

## コツ
- **同じチャットの中で続けて作る**と、絵のタッチがそろいます。1体目ができたら「同じタッチで、次は〇〇」と頼んでください。
- モンスターは**背景を透明**にしてもらいます。透明にできないときは**真っ白の単色**で大丈夫です（こちらで切りぬきます）。
- 送るときに「これはスライム」のように、どの画像か一言そえてください。

## 組みこみ（開発メモ）
- モンスターは `images/monsters/<名前>.png`（背景透明、余白を切りおとし、高さ 768px ほど）、背景は `images/bg/<名前>.jpg`（横 1536px ほど）に置く。
- `js/art.js` に画像のパスを書くと、プログラムで描く絵のかわりに画像が使われる（書いていないものは今までの絵のまま）。
