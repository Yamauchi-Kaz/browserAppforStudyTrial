# こたえてバトル

小学生向けの学習バトルゲーム（ブラウザー版）。
問題に日本語でこたえてモンスターをたおします。はやく正解するほど大ダメージ、時間切れになると自分がダメージを受けます。

## あそびかた

公開ページ（GitHub Pages）: https://yamauchi-kaz.github.io/browserAppforStudyTrial/

手元で遊ぶときは `index.html` をブラウザー（Chrome / Edge / Safari など）でひらくだけで動きます。

1. きょうか（さんすう・こくご・えいご・しゃかい・りか）、むずかしさ、こたえかたをえらんで「スタート！」
2. 問題のこたえを入力して Enter（🎤 ボタンで声でもこたえられます）
   - 正解 → 敵にダメージ（`10 + 30 × のこり時間の割合` ＋ 連続正解ボーナス）
   - 不正解 → 時間がのこっていれば何度でもやり直せます（「おしい！」も表示）
   - 時間切れ → 敵のこうげきで自分がダメージ、正解を表示して次の問題へ
3. 5体（さいごはボス）をたおせばクリア、自分のHPが0になるとゲームオーバー
4. とちゅうでやめるときは、左上の「⏸ やめる」（または Esc キー）。確認しているあいだは時間がとまります

## モンスターと音

- 敵は RPG によく出てくるモンスターを参考にした、このゲームオリジナルのキャラクターです（コロルン → ジュレキング → ダークまどうし → ストーンゴーレム → ボス テンリュウガ）。
- イラストは `art/` の SVG です。モンスターは「体」「パーツ（つばさ・うで・しっぽ・つえ）」「表情」を分けて描いてあり、`js/stage.js` で重ねて動かします。
  - 表情は場面で切りかわります: ふつう（まばたき）／こうげき（おこる）／ダメージ（いたがる）／まちがえたとき（あざわらう）／たおれる（目をまわす）。
  - 表情は `python3 tools/faces.py`、背景は `python3 tools/backgrounds.py` で作り直せます。
- コロルン・ジュレキング・テンリュウガは、キャラクター設定画（`art/source/*-sheet.png`）からポーズを切りぬいて使っています（`python3 tools/cut_sprites.py`。切りぬく範囲は同じファイルの `SHEETS`）。ふつう／ごきげん（あざわらう）／怒り（こうげき前）／どんぐりアタック／ひるみ／ふらふら（クリティカル）／たおれる を場面で切りかえます。
- BGM と効果音は `js/audio.js` で Web Audio API を使ってその場で合成しています（音声ファイルなし）。右上の 🔊 ボタンで音を消せます。
- スマホは画面を一度タッチしてから音が出ます。iPhone はマナーモードだと音が出ないことがあります。

## よみあげ

タイトル画面の「🔈 もんだいを よみあげる」がオンだと（はじめからオン）、問題が出るたびに読み上げます。

- 読み上げているあいだは制限時間がへりません。問題の 🔈 ボタンで、もういちど聞けます。
- 時間切れのときは「こたえは、〇〇」と読み上げます。
- ブラウザーの音声合成（speechSynthesis）を使うので無料です。おはなしモードでは、読みおわってから聞きとりを始めます。
- 読むと答えがわかってしまう問題（「山」の よみかた など）は、問題データの `speak` に書いた文（「この かんじの よみかたは なにかな？」）を読みます。

## おはなしモード（声でこたえる）

タイトル画面の「こたえかた」で「🎤 おはなし」をえらぶと、問題が出るたびに自動で聞きとりを始めます。話すだけで答えになり、まちがえても時間内ならすぐにまた聞きとります。

- ブラウザーにある音声認識（Web Speech API）を使うので無料です。Chrome / Edge / Safari で使えます（Firefox は未対応）。
- 聞きとりの候補を最大5つ受けとり、どれか1つが正解なら○にします。
- マイクを使うには HTTPS のページ（GitHub Pages など）でひらいてください。

## 正解の判定（ブラウザー内だけで判定・無料）

`js/judge.js` で、外部APIを使わずに判定しています。

- ひらがな／カタカナ、全角／半角、大文字／小文字、空白・記号のちがいをそろえる
- 「です」「だと思う」「答えは」などの前後の言葉をとりのぞく
- 数の問題は答えの中の数をとり出して比べる（`12`・`１２`・`12こ`・`十二` すべてOK）
- 長めの言葉は1文字くらいの打ちまちがいをゆるす（似ていれば「おしい！」）
- 「じゃない」「わからない」などをふくむ答えは不正解

## 問題の追加

`js/questions.js` の `FIXED` に追加します。漢字・ひらがななど、正解にしたい書き方を `answers` に並べてください。

- 問題文は小学1年生が読めるように、ひらがなで書きます。漢字を使うときは `{漢字|よみ}` と書くと、ふりがなが付きます（例: `「{大|おお}きい」の はんたいの ことばは？`）。
- `answers` の1つ目は、時間切れのときに「こたえは〇〇」と表示されるので、ひらがなにしておきます。
- ふりがなの付け忘れはテスト（`node --test tests/*.test.js`）で見つかります。

```js
{ subject: 'social', q: '日本の首都はどこ？', type: 'text', answers: ['東京', 'とうきょう', '東京都'] },
{ subject: 'science', q: '昆虫のあしは何本？', type: 'number', value: 6 },
```

声でこたえると、音声認識が同じ読みの漢字に変えてしまうことがあります（「そら」→「空」、「はな」→「鼻」）。そうなりやすい書き方は `voice` に並べておくと正解になります。読み方の問題では、その漢字そのものを入れておきます。

```js
{ subject: 'japanese', q: '「空」の訓読みは？（ひらがなで）', type: 'text', answers: ['そら'], voice: ['空'] },
```

さんすうの計算問題は毎回ランダムに作られます。メインは「1けた±1けた」（例: 3＋5、8−3）で、ときどき応用の「10〜19±1けた」（例: 12＋5、15−7。たし算の答えは20まで）が出ます。応用問題の割合は、やさしい 約1割／ふつう 約3割／むずかしい 約5割です。

## テスト

```sh
node --test tests/*.test.js
```
