# こたえてバトル

小学生向けの学習バトルゲーム（ブラウザー版）。
問題に日本語でこたえてモンスターをたおします。はやく正解するほど大ダメージ、時間切れになると自分がダメージを受けます。

## あそびかた

公開ページ（GitHub Pages）: https://yamauchi-kaz.github.io/browserAppforStudyTrial/

手元で遊ぶときは `index.html` をブラウザー（Chrome / Edge / Safari など）でひらくだけで動きます。

1. きょうか（さんすう・こくご・えいご・しゃかい・りか）、むずかしさ、こたえかたをえらんで「スタート！」
2. 問題のこたえを入力して Enter（🎤 ボタンで声でもこたえられます）
   - 正解 → 敵にダメージ（`10 + 30 × のこり時間の割合` ＋ 連続正解ボーナス）
   - 不正解 → 時間がのこっていれば何度でもやり直せます（「おしい！」も表示）
   - 時間切れ → 敵のこうげきで自分がダメージ、正解を表示して次の問題へ
3. 5体（さいごはボス）をたおせばクリア、自分のHPが0になるとゲームオーバー

## おはなしモード（声でこたえる）

タイトル画面の「こたえかた」で「🎤 おはなし」をえらぶと、問題が出るたびに自動で聞きとりを始めます。話すだけで答えになり、まちがえても時間内ならすぐにまた聞きとります。

- ブラウザーにある音声認識（Web Speech API）を使うので無料です。Chrome / Edge / Safari で使えます（Firefox は未対応）。
- 聞きとりの候補を最大5つ受けとり、どれか1つが正解なら○にします。
- マイクを使うには HTTPS のページ（GitHub Pages など）でひらいてください。

## 正解の判定（ブラウザー内だけで判定・無料）

`js/judge.js` で、外部APIを使わずに判定しています。

- ひらがな／カタカナ、全角／半角、大文字／小文字、空白・記号のちがいをそろえる
- 「です」「だと思う」「答えは」などの前後の言葉をとりのぞく
- 数の問題は答えの中の数をとり出して比べる（`12`・`１２`・`12こ`・`十二` すべてOK）
- 長めの言葉は1文字くらいの打ちまちがいをゆるす（似ていれば「おしい！」）
- 「じゃない」「わからない」などをふくむ答えは不正解

## 問題の追加

`js/questions.js` の `FIXED` に追加します。漢字・ひらがななど、正解にしたい書き方を `answers` に並べてください。

```js
{ subject: 'social', q: '日本の首都はどこ？', type: 'text', answers: ['東京', 'とうきょう', '東京都'] },
{ subject: 'science', q: '昆虫のあしは何本？', type: 'number', value: 6 },
```

さんすうの計算問題は、むずかしさに合わせて毎回ランダムに作られます。
